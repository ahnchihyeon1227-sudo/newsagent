# Requirements: Briefing Agent

## 개요

매일 아침 관심 키워드 기반으로 뉴스를 자동 수집·스코어링·요약하여 마크다운 브리핑 파일을 생성하는 Python AI Agent.

---

## 병목 정보

| 항목 | 내용 |
|------|------|
| 자동화 대상 Task | 관심 키워드 기반 뉴스 수집 → 중요도 판단 → 마크다운 브리핑 생성 |
| 실행 빈도 | 매일 1회 |
| 수동 소요 시간 | 약 30~40분 |
| 병목 원인 | 여러 사이트 직접 탐색, 중복 기사 수동 필터링, 중요도 판단 주관적 |

---

## 사용자 시나리오

1. 사용자가 `test-input/case-1.json`에 키워드를 입력한다.
2. Agent가 Google News RSS를 통해 뉴스를 수집하고 AWS Bedrock(Claude 3 Haiku)으로 관심도를 판단한다.
3. 필터링·중복 제거 후 브리핑 파일을 생성한다.
4. 사용자는 `briefing_YYYYMMDD.md` 파일 하나만 읽는다.

---

## 수용 기준 (Acceptance Criteria)

**AC-1.** `python main.py --input test-input/case-1.json` 실행 후 `briefing_YYYYMMDD.md` 파일이 현재 디렉터리에 생성된다.

**AC-2.** 생성된 파일의 최상단 메타데이터 헤더에 `Generated At`, `Total Collected`, `Filtered Out`, `Estimated Tokens` 4개 필드가 모두 포함된다.

**AC-3.** 브리핑 본문(헤더 제외)의 문자 수가 800자 이상 3000자 이하다.

**AC-4.** 브리핑 본문에 기사 항목이 3개 이상 포함된다.

**AC-5.** 각 기사 항목에 제목, 출처, 요약(2문장 이상), 관심도 스코어(0~10) 4개 필드가 포함된다.

**AC-6.** 관심도 스코어가 3점 미만인 기사는 브리핑 본문에 포함되지 않는다.

**AC-7.** `main.py` 실행 시작부터 파일 생성 완료까지 경과 시간이 60초 이내다.

**AC-8.** `keywords`가 빈 배열(`[]`)인 입력 파일로 실행 시, 브리핑 파일을 생성하지 않고 표준 출력에 `ERROR: 키워드가 없습니다`를 출력한다.

**AC-9.** 수집된 전체 기사 중 관심도 3점 미만 기사 비율이 70%를 초과할 경우, 표준 출력에 `WARNING: 관련 기사가 적습니다`를 출력한다.
